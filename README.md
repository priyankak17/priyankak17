## 🧪 ML Engineering Portfolio

A hands-on portfolio focused on model training, systems tradeoffs, reproducibility, and publishing deployable artifacts.

### 🔹 Deep Learning & Generative AI Experiments

**Repository:** [Deep-Learning-using-PyTorch](https://github.com/priyankak17/Deep-Learning-using-PyTorch)  
**Case studies:** [ML Engineering Portfolio](https://priyankak17.github.io/pynk17/portfolio.html)  
**Model artifacts:** [Hugging Face · pynk17](https://huggingface.co/pynk17)

| Experiment | What I worked on | Notebook / Model |
|---|---|---|
| **Custom DDPM / UNet** | Built diffusion models from a small UNet baseline to a larger 256 × 256 UNet2D DDPM with attention, BF16, gradient accumulation and periodic sampling | [Notebook](https://github.com/priyankak17/Deep-Learning-using-PyTorch/blob/main/pynk_fewshot_unet2d_diff_model.ipynb) · [Model](https://huggingface.co/pynk17/pk_fewshot-aur-model) |
| **Stable Diffusion systems comparison** | Fine-tuned Stable Diffusion v1.5 across FP32, FP16, and FP16 + gradient checkpointing to compare precision and memory-oriented training configurations | [Notebook](https://github.com/priyankak17/Deep-Learning-using-PyTorch/blob/main/Stable_diff_fine_tuning.ipynb) · [FP32](https://huggingface.co/pynk17/sd-naruto-fp32-baseline) · [FP16](https://huggingface.co/pynk17/sd-naruto-fp16) · [FP16 + GC](https://huggingface.co/pynk17/sd-naruto-fp16-grad-checkpointing) |
| **BLOOM-7B1 LoRA** | Adapted a 7B-scale causal LM with PEFT / LoRA while training about 0.11% of total parameters, using FP16 and gradient checkpointing | [Notebook](https://github.com/priyankak17/Deep-Learning-using-PyTorch/blob/main/PEFT_Finetune_Bloom7B_LoRa.ipynb) · [Adapter](https://huggingface.co/pynk17/pkbloom-7b1-lora) |
| **PyTorch foundations** | Worked through tensor fundamentals and deep learning building blocks used throughout the later experiments | [Overview](https://github.com/priyankak17/Deep-Learning-using-PyTorch/blob/main/PyTorch_DL_Overview_00.ipynb) · [Basics](https://github.com/priyankak17/Deep-Learning-using-PyTorch/blob/main/PyTorch_Basics_01.ipynb) |
